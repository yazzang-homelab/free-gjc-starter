free-gjc-starter · 왕초보 풀 가이드

컴퓨터에 무료 AI 코딩 비서(gjc) 깔기. 터미널 여는 법부터 → 프로그램 설치 → 무료 키 발급 → 설정까지 전부.

순서
0. 어떤 방식으로 쓸지 고르기 1. 준비물 2. 터미널 여는 법 3. gjc 설치 4. 이 무료 세팅 설치 5. 무료 API 키 발급 6. 키를 컴퓨터에 넣기 7. 메인 두뇌 정하기 (A/B) 8. 확인 & 첫 대화 문제 해결
⚠ 딱 하나만 지키세요 — 발급받은 키는 비밀번호입니다. 남에게 보여주거나 파일·채팅에 붙여넣지 말고, 아래 안내대로 본인 PC의 환경변수에만 넣으세요. 이 세팅 파일에는 키가 이름으로만 들어갑니다.

0. 어떤 방식으로 쓸지 고르기

메인 두뇌(가장 똑똑한 역할)를 뭘로 할지 두 갈래입니다. 나머지 일꾼들은 두 경우 다 무료입니다.

방식 A Gemini를 메인으로 추천

구글 계정으로 로그인만 하면 됩니다. 카드 등록 X.
  • Google AI 구독 있음 → 그대로 사용
  • 구독 없음 → Antigravity 무료 티어(개인 Gmail, 카드 X)로도 됩니다
필요한 무료 키: OpenRouter, NVIDIA (2개)
방식 B Gemini 없이, NVIDIA 모델을 메인으로

구글/Gemini를 아예 안 쓰고 싶을 때. 로그인만 안 하면 NVIDIA의 무료 DeepSeek V4.1 Flash가 자동으로 메인이 됩니다.
  • 설정 수정 없음 — 로그인을 건너뛰기만 하면 됨
필요한 무료 키: OpenRouter, NVIDIA (2개)

※ 메인은 Gemini 1순위 → NVIDIA DeepSeek V4.1 Flash 2순위 → OpenRouter Nemotron 3 Ultra 3순위로 자동 전환됩니다. 방식 A·B 모두 키는 같은 2개입니다.

1. 준비물 (5분)

  • 구글 계정 하나 (Gmail 있으면 됨) — 무료 키 사이트 로그인·Gemini 로그인에 씀
  • 인터넷 되는 윈도우 PC 또는 맥
  • 돈 안 듭니다.

2. "터미널" 여는 법

터미널 = 컴퓨터에 글자로 명령을 내리는 창입니다. 여기다 아래 명령들을 복사-붙여넣기합니다.

🪟 윈도우
  1. 키보드 ⊞ 윈도우 키를 누릅니다.
  2. 터미널 이라고 칩니다. (안 뜨면 powershell)
  3. Windows Terminal 또는 Windows PowerShell 클릭 → 창이 뜹니다.
🍎 맥
  1. ⌘ + 스페이스 를 동시에 → 검색창.
  2. 터미널 또는 terminal 입력.
  3. 터미널(Terminal) 클릭.
복사-붙여넣기 & 실행 — 아래 상자 명령을 복사(Ctrl+C, 맥 ⌘+C) → 터미널에 붙여넣기(윈도우: 마우스 오른쪽 클릭, 맥: ⌘+V) → Enter 를 눌러야 실행됩니다.

3. gjc 설치

🪟 윈도우 (PowerShell)
irm bun.sh/install.ps1 | iex

👉 끝나면 창을 닫고 터미널을 새로 여세요. 그다음:

bun install -g gajae-code
🍎 맥 / 리눅스
curl -fsSL https://bun.sh/install | bash

👉 끝나면 터미널을 새로 여세요. 그다음:

bun install -g gajae-code
확인: gjc --version 을 치고 버전 숫자가 나오면 성공.
❔ command not found / 인식할 수 없습니다 → 터미널을 완전히 닫고 다시 여세요.

4. 이 무료 세팅 설치

🪟 윈도우
git clone https://github.com/yazzang-homelab/free-gjc-starter.git
cd free-gjc-starter
powershell -ExecutionPolicy Bypass -File .\install.ps1
🍎 맥 / 리눅스
git clone https://github.com/yazzang-homelab/free-gjc-starter.git
cd free-gjc-starter
bash install.sh

❔ git ... 없음 → 윈도우는 git-scm.com에서 설치, 맥은 xcode-select --install 후 다시 시도.
🔄 예전에 설치한 분(업데이트): 설치 스크립트는 이미 있는 ~/.gjc-free/agent/config.yml을 덮어쓰지 않습니다. git pull 후 맥/리눅스는 bash install.sh --force, 윈도우는 powershell -ExecutionPolicy Bypass -File .\install.ps1 -Force (기존 파일은 config.yml.bak-날짜로 백업).
❔ 이 시스템에서 스크립트를 실행할 수 없으므로 / UnauthorizedAccess → 윈도우 기본 보안 정책이 .ps1을 막는 것. 위 명령(-ExecutionPolicy Bypass)으로 실행하면 됩니다.

5. 무료 API 키 발급

일꾼 AI가 쓸 무료 열쇠를 받습니다. 카드 등록 필요 없어요. 각 사이트에서 구글 로그인 → Create Key → 이름 입력 → 만들기 → 키 복사.

사이트발급 링크키 형태무료 한도(공식)
OpenRouteropenrouter.ai/keyssk-or-v1-...:free 모델 분당 20회, 하루 50회 (크레딧 $10 이상 충전 계정은 하루 1,000회)
NVIDIA NIMbuild.nvidia.com → Get API Keynvapi-...분당 40회 (전화번호 인증 필요)

ℹ️ 예전 버전의 Groq는 뺐습니다. Groq 무료는 분당 8,000토큰 한도라 gjc 요청 한 번(빈 폴더에서도 약 1.2만 토큰)이 매번 413 Request too large로 거절됩니다.

키는 생성 직후 한 번만 보이는 경우가 많습니다. 바로 복사해서 다음 단계로 가세요.

6. 키를 컴퓨터에 넣기

여기에_키 부분만 방금 복사한 진짜 키로 바꿔서 붙여넣으세요. (안 쓰는 키 줄은 빼도 됩니다)

🪟 윈도우 (PowerShell)
setx OPENROUTER_API_KEY "여기에_키"
setx NVIDIA_API_KEY "여기에_키"

👉 그리고 터미널을 닫고 새로 여세요. (setx는 새 창부터 적용)

🍎 맥 / 리눅스
echo 'export OPENROUTER_API_KEY="여기에_키"' >> ~/.zshrc
echo 'export NVIDIA_API_KEY="여기에_키"'     >> ~/.zshrc
source ~/.zshrc

(오래된 셸이면 ~/.zshrc → ~/.bashrc 로 바꿔 쓰세요.)

7. 메인 두뇌 정하기

방식 A Gemini를 메인으로 (로그인만)

터미널에 free-gjc 입력 → gjc가 뜨면 본인 구글 계정으로 로그인: 
/login google-antigravity
기본값이 이미 무료 Gemini(google-antigravity/gemini-3.1-pro-low:high)라 위 로그인만 하면 바로 됩니다. (설정 수정 불필요)
⚠️ 로그인 전에 — 브라우저에 구글 계정을 여러 개(개인+회사/학교) 로그인해 두면 엉뚱한 조직(Workspace) 계정으로 인증돼 GOOGLE_CLOUD_PROJECT ... 오류가 납니다. 시크릿(인프라이빗) 창에서 개인 지메일 1개만 로그인한 채로 진행하세요.
✅ 무료로 됩니다. Google이 2026-06-18 옛 Gemini CLI 무료(Code Assist for individuals)를 종료하고 Antigravity의 $0 Individual 플랜으로 옮겼습니다. 개인 Gmail이면 카드 없이 Gemini 3.1 Pro를 씁니다. (2026-10-09 "Gemini 앱 무료는 Flash-Lite만" 소식은 Gemini 웹/앱 이야기입니다.)
🪫 무료 할당량 주의. Google은 "주간 사용량"이라고만 하고 숫자를 공개하지 않습니다. 많이 쓰면 429가 나고, 그땐 NVIDIA DeepSeek V4.1 Flash로 자동 전환됩니다.
ℹ️ Antigravity의 Claude 모델은 무료로 기대하지 마세요 → 무료 계정이 고르면 404. 기본값 Gemini 3.1 Pro를 쓰세요. (옛 /login google-gemini-cli 무료 경로는 종료됨)

방식 B Gemini 없이 NVIDIA 모델을 메인으로

아무것도 안 해도 됩니다. 구글 로그인을 안 하면 메인이 자동으로 다음 순서로 넘어갑니다: 
modelRoles:
  default:
    - google-antigravity/gemini-3.1-pro-low:high      # 로그인 안 했으면 건너뜀
    - nvidia/deepseek-ai/deepseek-v4.1-flash          # ← 방식 B의 실제 메인
    - openrouter/nvidia/nemotron-3-ultra-550b-a55b:free
GLM-5.3(nvidia/z-ai/glm-5.3)도 무료지만 2026-10-15 실측에서 "OK" 한 마디에 270초(DeepSeek V4.1 Flash 56초)가 걸려 메인 기본값에서 뺐습니다. 쓰려면 ~/.gjc-free/agent/config.yml의 default: 목록 맨 위에 - nvidia/z-ai/glm-5.3을 넣으세요.

8. 확인 & 첫 대화

free-gjc config get modelRoles       # 역할별 모델이 찍히면 설정 OK
free-gjc -p --no-session "안녕? 넌 누구야?"
AI가 대답하면 성공! 🎉 이제 이렇게 씁니다: 
free-gjc                              # 대화형으로 켜기
free-gjc "파이썬으로 계산기 만들어줘"    # 한 번에 시키기
평소 쓰던 gjc(다른 프로필)와 완전히 따로 돌아가니 안심하세요.

문제 해결

증상해결
command not found / 인식할 수 없습니다터미널을 완전히 닫고 새로 열기. 안 되면 3번 설치 재실행.
git ... 없음4번 아래 안내대로 Git 먼저 설치.
No API key / 401 / unauthorized그 provider 키를 6번대로 다시 넣고 터미널 새로 열기. 키 오타·잘못 복사 확인.
Cloud Code Assist API error (404) / Requested entity was not found로그인은 됐지만 그 모델이 계정 등급에 없음. 무료 계정에서 Opus 등 Anthropic/Claude(Antigravity 유료 전용) 모델을 고른 경우가 대표적.
→ 무료는 default를 google-antigravity/gemini-3.1-pro-low:high(이 세팅 기본값)로 두면 됨. 계정 잘못 로그인 시 free-gjc /logout 후 개인 Gmail로 재로그인.
AI가 429 / quota / RESOURCE_EXHAUSTED무료 할당량 소진. 메인은 자동으로 다음 모델로 넘어가고, 목록 전부가 429면 잠시 뒤 재시도. OpenRouter :free는 하루 50회(UTC 자정 리셋)라 가장 먼저 바닥납니다.
413 Request too large / TPM: Limit 8000예전 버전의 Groq 설정. Groq 무료는 gjc 요청을 못 받아서 뺐습니다. git pull 후 4번의 --force 재설치.
model_decommissioned / z-ai/glm-5.2·groq-free·nvidia-nim·openrouter-free 관련 오류예전 버전 설정. 이 세팅은 이제 gjc 내장 nvidia·openrouter provider를 씁니다. git pull 후 4번의 --force 재설치.
no match / 모델 못 찾음무료 모델 이름이 바뀐 것. free-gjc models로 지금 쓸 수 있는 이름을 확인해 ~/.gjc-free/agent/config.yml 수정.
OpenRouter 무료 목록 · NVIDIA 무료 엔드포인트
402 Payment Required (OpenRouter):free가 없는 유료 모델을 골랐고 크레딧이 0원인 경우. 청구 없이 거절된 것이니 :free 모델로 바꾸세요. 크레딧을 충전했다면 유료 모델은 실제로 과금됩니다.
only available on agentic harnesses (403)OpenRouter thinkingmachines/inkling:free처럼 등록 앱 전용 무료 모델. gjc에서는 안 되니 다른 :free 모델 사용.
Gemini 로그인 창이 안 열림터미널에 표시된 주소를 복사해 브라우저 주소창에 직접 붙여넣기.
Provider stream timed out while waiting for the first event / stalled while waiting for the next event무료 티어 모델이 첫 토큰을 늦게 뱉어서(추론 모델 + 대기열 + 긴 대화) gjc의 스트림 감시 타이머(기본 100초)에 걸린 것. 최신 free-gjc 런처는 타이머를 넉넉하게(첫 응답 10분/유휴 5분) 잡아두니 repo를 git pull 후 설치 재실행. 그래도 나면 대화가 너무 긴 것 — /compact로 줄이거나 새 세션 시작.
🗨️ 혼자 해결 안 되면 — 오픈카톡으로 물어보세요: open.kakao.com/o/pW7JOXDi (이 세팅 올린 사람이 직접 답변합니다. gjc 원작자와는 무관 ㅎㅎ)
안심하세요 — 이 repo·이 페이지 어디에도 API 키·개인정보가 없습니다. 키는 당신 PC에만 저장됩니다. 남과 공유할 땐 이 repo 주소만 주면 되고, 기존 gjc 설정은 건드리지 않습니다(~/.gjc-free에만 설치).
